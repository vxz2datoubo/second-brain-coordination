# E56 System Discovery

The main discovery is architectural: canonical bytes must represent stable evaluated semantics, while executable identity and transport details must be bound as environment evidence rather than compared for equality. The first Provider matrix supplied a concrete counterexample, and the corrected matrix confirmed the separation across two Python versions and three hash seeds.

The archive collector also established a practical portability rule: do not assume a particular `gh api` output flag when a byte-preserving subprocess stream is sufficient. This is an E56 tooling lesson, not a cross-project change proposal.

No new market, account, credential, data-source, model, trading or QCLAW capability was discovered or promoted.
