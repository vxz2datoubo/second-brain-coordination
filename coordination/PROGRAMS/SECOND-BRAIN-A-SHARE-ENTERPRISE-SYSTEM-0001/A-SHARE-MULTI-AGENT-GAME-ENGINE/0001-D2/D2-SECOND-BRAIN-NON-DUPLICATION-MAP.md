# D2 Second-Brain Non-Duplication Map

D2 is a synthetic decision-mechanics consumer. It does not create a second
memory, evidence, knowledge-graph, validation, or governance runtime.

| Shared capability | System of record | D2 behavior |
| --- | --- | --- |
| Long-term memory and query context | PR #57 accepted runtime | Future candidate-only consumer. |
| Candidate gateway | PR #58 candidate gateway | No direct dependency until accepted. |
| Evidence and KnowledgeAtom authority | Mother-system core | D2 accepts only synthetic references in this phase. |
| Decision and Forecast records | Mother-system contracts | D2 does not write either record in Stage A. |
| Validation pipeline | Existing governed validation path | D2 exposes test evidence only, not market validation. |

No D2 output may be promoted to a knowledge fact, trading signal, or trade
instruction merely because its synthetic tests pass.
