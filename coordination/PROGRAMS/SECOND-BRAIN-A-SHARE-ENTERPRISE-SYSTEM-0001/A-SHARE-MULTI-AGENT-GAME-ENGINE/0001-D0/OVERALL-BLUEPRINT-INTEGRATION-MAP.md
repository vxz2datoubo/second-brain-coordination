# Overall Blueprint Integration Map

```text
governed sources and capability cards
  -> mother-system evidence and knowledge contracts
  -> point-in-time market state and rule snapshot
  -> latent participant hypotheses and evidence credibility
  -> candidate action / advantage / mismatch / counter-scenario records
  -> existing validation and decision-review consumers
  -> candidate LearningPacket and knowledge retrieval
```

The multi-agent engine is a level-one trading research capability, not an independent data, memory, replay or order system. It consumes governed inputs and produces candidate research artifacts. The second brain retains lineage, conflicts, UNKNOWNs, review and evolution records. Numerical simulation, when approved later, remains distinct from LLM narration.

W13-like participant observation provides facts, proxies, alternatives and evidence quality. This module consumes those inputs for hypothesis simulation but may not write its narratives back as observation facts. WorkBuddy owns local runtime and data-capability facts; QCLAW owns candidate knowledge digestion; Codex owns contracts, static validation and implementation proposals; GPT arbitrates authority and promotion.
