# Advantage Activation Model

An advantage is an evidence-conditioned capability, not a permanent family property. The future model evaluates `activation`, `decay`, `reversal` and `unknown` states using market phase, rule feasibility, inventory horizon, liquidity, volatility, event state, capacity, data capability and evidence coverage.

Example: capital size can be an advantage in a liquid, multi-day inventory context but a weakness when exit capacity is constrained. A fast strategy can be advantaged with verified event timing yet disadvantaged when source time is missing or delayed. The model records both the hypothesized mechanism and the conditions under which it fails. It never infers deliberate adversarial intent merely because a weakness is exposed.
