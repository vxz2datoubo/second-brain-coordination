# System discovery and opportunity report

## Discovery

The canonical W3 runtime is a valuable reuse base but was built around offline market-source candidates. Its candidate-only safeguards are an advantage for the first conversational slice, but its data model has no adequate distinction between user assertion, assistant output, episode evidence, current state and historical state.

## Opportunity

An additive conversation adapter can provide the requested mobile/web/desktop experience without forcing a new storage or retrieval authority. The smallest credible next step is a synthetic, candidate-only A-E slice with a single contract evolution and negative leakage tests.

## Risks discovered

- Treating native product memory as a complete durable archive would create false coverage claims.
- Treating an arbitrary atom update as a correction would erase history.
- Allowing all `superseded` atoms by default would leak stale state into a current answer.
- Coupling CLTM to unfinished E48 or a private repository would violate the active route.
